# Deeper evidence and disclosure boundary

The public package intentionally does not include the full private implementation or every preserved artifact.

## Exported

- primary result JSON
- exact canonical-observation excerpt
- deterministic procedure crops
- secondary Kernel evaluation, provenance note, and UI crop

## Held private

- full adversarial Design
- full implementation patch
- complete Standing Core packet
- Layer B fixture
- pre-Actual execution-contract fixture
- full-screen original chat/UI screenshots
- full procedure chat logs and full private branch history

The held-private artifacts are not required to follow the public three-responsibility proof chain. Their private SHA-256 and preservation references are recorded where needed in [the provenance manifest](../../PROVENANCE_MANIFEST.md). No decision about full-source release or licensing is made here.
